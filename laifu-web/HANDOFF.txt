二、首次启动
以下命令在解压后的 laifu-web 根目录运行，使用 macOS/Linux shell；Windows 可使用 WSL 或将环境变量语法替换为 PowerShell 写法。
按 package.json 使用 Node.js >=22、pnpm 12.3.4，然后执行：
  pnpm install --frozen-lockfile
  cp apps/assessments/.env.example apps/assessments/.env.local
  cp apps/admin/.env.example apps/admin/.env.local
  cp workers/assessment-api/.dev.vars.example workers/assessment-api/.dev.vars

编辑本地配置：
  测评站默认 API 为 http://localhost:8787，主站为 http://localhost:3001。
  Worker 的 ADMIN_API_TOKEN 请替换成至少 32 字符的随机令牌；PUBLIC_ORIGINS 设为 http://localhost:3002。
  后台 ASSESSMENT_API_URL=http://localhost:8787。
  后台 ASSESSMENT_API_ADMIN_TOKEN 与 Worker 的 ADMIN_API_TOKEN 必须相同。
  后台 ADMIN_MVP_USERNAME、ADMIN_MVP_PASSWORD、ADMIN_MVP_SESSION_SECRET 填入自行生成的本地值。
  后台 ADMIN_ALLOWED_ORIGINS 可设为 localhost:3003。
  生成随机令牌可用：node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"

初始化本地数据库：
  pnpm --filter @laifu/assessment-api db:migrate:local

分别在四个终端运行：
  PORT=3001 pnpm dev:website
  PORT=3002 pnpm dev:assessments
  PORT=3003 pnpm dev:admin
  pnpm dev:api

只开发主站时，仅安装依赖并启动 dev:website 即可，不必配置其他应用。
主站 http://localhost:3001；测评站 http://localhost:3002；后台 http://localhost:3003；API http://localhost:8787/health。

三、构建与验收
  pnpm build                 构建三个前端，并检查 Worker
  pnpm exec playwright install chromium
  pnpm check                 完整工程验收（含构建、端到端、产物与依赖审计）

主站和测评站输出各自 out/ 静态目录；后台是服务端应用，不能作为静态目录交付。
后台 Cloudflare 构建：pnpm --filter @laifu/admin build:cf。
生产构建：pnpm build:production；该脚本固定了当前 Pages/Worker 域名。换账号或域名前先修改 scripts/build-production.mjs 和对应 Wrangler 配置。
workers/assessment-api/wrangler.jsonc 中的 D1 database_id 属于当前部署环境；新账号需要自行创建 D1 并替换绑定。
生产账号权限、域名权限、Worker Secrets 和真实数据库须由项目负责人另外移交。
部署步骤见 docs/architecture.md；本交付没有执行部署或线上数据库操作。
