## 规范来源

- 唯一令牌源：`docs/design/system.md` 的 YAML frontmatter。
- 主站 CSS 令牌由构建前脚本生成，不手工维护生成文件。
- 主站以真实照片为主要视觉，照片保留来源和许可记录；每个 section 在配图前必须登记 none、photo 或 illustration 判断，插图只允许用于抽象工具、问答、目录或提示。少量保留插图只把源 SVG 中的原始强调色替换为当前主色，其余颜色和图形保持不变。Hero 与正文配图禁止复用同一资产。
- 原始 Logo 不改色；公开副本与源文件逐字节核对。
- 图标使用现有内联线性 SVG 或 Lucide，不依赖 Font Awesome。

## 已确认规则

- 主站公开页面不使用渐变和阴影。
- 普通组件最大圆角为 2px；品牌 Logo 本身的曲线不属于组件圆角。
- 全站阅读区仅使用米白、浅灰、暖灰三类中性表面，首页导览、菜单和内容卡片使用中性底色；子页标题区按最新反馈改为浅鼠尾草绿栏目与绿调近白色标题底。橙色仅用于主要操作；按钮默认橙底墨色字，悬停深橙底米白字；主按钮保持 20px / 400、无下划线和 2px 圆角。次级操作保持透明细线框；浅底与深底分别采用墨色与米白键盘焦点环。
- 顶部导航、服务菜单、移动导航和页脚栏目使用中文。
- 页面标题、章节标题、眉题与行动区只显示中文；英文仅保留在品牌标志、姓名、专业缩写和必要术语中。
- 桌面 Hero、章节、CTA 和页脚采用统一 12 栏；29 个子页统一为 2 栏栏目 / 10 栏标题的色带、原有通栏照片与整合开篇内容，窄屏顺序堆叠，无图页不留占位。导语、补充段落与相关操作共用同一阅读宽度，不再散落为独立模块；首页 cover 与正文构图保持独立，高度随内容增长。
- 文字、行距、间距、描边与控件尺寸使用统一令牌；提示内容使用独立纵向结构，不承接页面网格。
- 插图不使用动效；交互只做颜色反馈，减少动效模式禁用过渡。导航保持固定高度，避免滚动时布局跳动。
- 交接十字只出现在独立章节边界，不出现在 Hero 或章节内部。
- 斜线纹理仅保留在 Hero 角落内距区域；正文和 CTA 不叠加装饰纹理。
- 课程与工作坊归在线下活动的桌面/移动子菜单、页脚与面包屑，原地址保持可访问。
