# 资源中心与首页阅读器

## 运营步骤

1. 打开 CMS「官网页面」中的「资源中心」，展开需要更新的资源条目，上传或关联 DOCX、PDF、EPUB 文件。
2. 确认文件使用权并允许公开使用，填写资源标题与简介，保存草稿、预览后发布资源中心页面。
3. 打开「首页呈现 → 免费指南 → 首页展示资源（最多三个）」。每个区块选择一个资源，可刷新资源列表；删除不用的区块、拖动调整顺序，封面图片可选。
4. 保存草稿并预览，确认后发布首页。未关联文件的原首页示意区块需要重新选择或移除，不会自动当作正式资源展示。

只有资源中心已经发布、附件已经授权公开且格式为 DOCX、PDF、EPUB 的条目可选。首页最多三个，不允许重复。选择零个时展示整理中的提示和资源中心入口。

资源中心点击「在线阅读」会在新标签页打开无动画阅读器；首页点击封面会在原区块展开并使用翻页效果。减弱动态效果偏好启用时，首页也直接切页。两种入口都支持上一页、下一页、页码跳转和下载原文件。手机端使用单页，桌面首页使用双页。

## 格式与限制

- PDF 保留原文件页面和字体，使用本地 PDF.js worker、CMaps、标准字体和 WASM 渲染。
- DOCX 保留正文层级、列表、表格和嵌入图片，转换后按阅读区域分页。复杂 Word 版式不会逐像素还原；需要保留原样时应使用 PDF。
- EPUB 按 OPF spine 顺序读取章节，支持章节锚点和 PNG/JPEG/GIF/WebP 图片。书内脚本、样式及远程图片不会执行或加载；加密、损坏的内容会提示失败。
- 单个文件最多 25MB，解压总量最多 80MB，最多 600 个阅读页。旧 DOC、表格、音视频、ZIP 等仍沿用原文件或播放入口。
- DOCX 和 EPUB 阅读文字使用本地完整 Noto Sans SC，字体只随阅读器加载；首页无需加载完整阅读字体或文档解析库。

## 数据与验证

资源中心的页面 JSON 是资源标题、简介和附件关系的唯一来源。每个资源在保存时获得稳定的 `id`；旧条目可从原附件编号生成兼容标识。替换附件、编辑标题均保留资源标识。首页使用现有指南链接字段存储 `/resources/read/?resource=<id>`，无需数据库结构迁移。

阅读器页面与文件代理都重新查询已发布资源；未发布、撤销授权、移入回收站或解除附件关联后不可继续通过阅读器获取。代理只读取配置的 CMS 同源媒体文件，不接受客户端文件 URL。首页的 CMS 投影每次重新校验资源授权；网站呈现缓存仍遵循现有发布刷新和最多 60 秒缓存周期。

执行 `node scripts/prepare-reader-assets.mjs` 可从锁定的 `pdfjs-dist` 依赖生成本地 PDF 运行资产，常规 `assets:prepare` 也会执行。完整阅读字体使用与官网字体相同的官方 Noto Sans SC 源文件，随附 OFL 许可。

相关文档：[Mammoth](https://github.com/mwilliamson/mammoth.js)、[PDF.js](https://mozilla.github.io/pdf.js/examples/)、[fflate](https://github.com/101arrowz/fflate)、[DOMPurify](https://github.com/cure53/DOMPurify)。
